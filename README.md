# Papers Review — Reasonix 开发包

本目录包含：

- `REASONIX_IMPLEMENTATION_INSTRUCTION.md`：可直接交给本地 Reasonix 的完整开发指令。
- `papers-review-ui-reference.html`：无需依赖、可直接在浏览器打开的交互式视觉参考。
- `papers-review-ui-reference.png`：上述 HTML 在 1536×1024 下的预览截图。
- `original-ui-concept.png`：需求讨论阶段确认的原始视觉概念图。

建议将本目录整体复制到计划开发扩展的工作区下，例如：

```text
project-root/
└── references/
    ├── REASONIX_IMPLEMENTATION_INSTRUCTION.md
    ├── papers-review-ui-reference.html
    ├── papers-review-ui-reference.png
    └── original-ui-concept.png
```

然后把 `REASONIX_IMPLEMENTATION_INSTRUCTION.md` 全文交给 Reasonix。真实 PR 保存页只作为本地结构参考，不建议提交进公开仓库；其中可能包含私有仓库信息和会话相关数据。
